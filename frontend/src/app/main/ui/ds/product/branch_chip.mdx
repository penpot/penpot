# BranchChip

The button that names the branch the open file is and opens the branch
switcher.

<Canvas of={BranchChip.Default} />

## Variants

`is-open` draws the chip pressed while its popover is shown.

<Canvas of={BranchChip.Open} />

Long names are truncated with an ellipsis; the chip never grows past its
container.

<Canvas of={BranchChip.LongName} />

## Technical notes

The label is mandatory. Any other prop (`on-click`, `title`, `aria-*`)
goes to the underlying `button`, which already carries
`aria-haspopup="dialog"` and `aria-expanded`.

```clj
[:> branch-chip* {:label (:name branch)
                  :is-open open?
                  :on-click on-toggle}]
```

## Usage guidelines (design)

### Where to use

In the workspace header row, only when the file has branches.

### Interaction / Behavior

Clicking it opens or closes the branch switcher. The popover is the
caller's: the chip only draws the trigger.
