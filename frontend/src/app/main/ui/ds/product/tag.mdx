# Tag

A short, static status word that says what something is or where it
stands.

<Canvas of={Tag.Default} />

## Variants

`label` (the default) is a small code-font tag that names a type or a
state: Board, Main component, Verified, Clash.

`pill` is a rounded word or count at the end of a row: Choose, Decided,
3 edits, 14 shapes.

<Canvas of={Tag.Pill} />

The tone colours the text and its background. Text keeps the case it
is written in; the tag never turns it uppercase.

<Canvas of={Tag.Tones} />

`icon` goes before the text.

<Canvas of={Tag.WithIcon} />

## Technical notes

```clj
[:> tag* {:tone "warning"} (tr "workspace.branches.review.tag.clash")]
[:> tag* {:tone "success" :variant "pill"} (tr "workspace.branches.review.decided")]
```

## Usage guidelines (design)

Use it for a word that does not act. For a filter, use `FilterChip`.
