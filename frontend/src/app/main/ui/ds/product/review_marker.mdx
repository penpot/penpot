# ReviewMarker

The mark a design review leaves on the canvas: a round mark with the
number of a comment, or a square one with the task icon.

<Canvas of={ReviewMarker.AllMarkers} />

## Variants

- `type`: `comment` (default) or `task`.
- `state`: `default`, `active` (the one open now), `resolved` (a settled
  comment: a tick replaces its number) and `lost` (its layer was deleted:
  a dashed orange outline) and `ghost` (what stays where a group of marks
  fanned out from).
- `counter`: the number of items a mark holds, in a white bubble on its
  top right corner. A comment mark with several comments has no `label`,
  so it shows the comments icon.

## Technical notes

It renders a `button`. The caller names it with `aria-label` and handles
`on-click`; `label` is the number of a comment.

```clj
[:> review-marker* {:label (str (:seqn thread))
                    :state (if open? "active" "default")
                    :aria-label (tr "workspace.review.marker.comment" (:seqn thread))
                    :on-click on-open}]
```
