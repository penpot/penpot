# BranchRow

A branch in a short list, such as the branch switcher or the dashboard
branches popover. Clicking it opens the branch.

<Canvas of={BranchRow.Default} />

## Variants

The branch the open file is shows a tick and cannot be opened again.

<Canvas of={BranchRow.Current} />

Children go to the end of the row, usually a `BranchStatus`.

<Canvas of={BranchRow.WithStatus} />

## Technical notes

The label is mandatory. The row is a `button`; any other prop
(`on-click`, `data-*`) goes to it.

A label too long for the row ends in an ellipsis, and the row then
carries the full label as its `title`, so it shows on hover (the current
row too, though it is disabled). A label that fits gets no `title`.

```clj
[:> branch-row* {:label (:name branch)
                 :data-branch (dm/str (:branch-file-id branch))
                 :on-click on-open}
 [:> branch-status* {:ahead (:ahead branch) :behind (:behind branch)}]]
```
