# ProgressBar

A thin bar filled by how much of a total is done.

<Canvas of={ProgressBar.Default} />

## Technical notes

It takes the width of its container: size it with `class`. Set
`--progress-bar-fill-radius` there to round the end of the fill. Add
`aria-hidden` when text next to it already says the same.

```clj
[:> progress-bar* {:value closed
                   :total total
                   :class (stl/css :tasks-progress)}]
```
