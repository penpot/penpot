# TaskStatus

The state of a task: a dot in the colour of the state before its name.

<Canvas of={TaskStatus.AllStatuses} />

## Technical notes

`status` is one of `open`, `done`, `reopened`, `verified` and `wont-do`;
`label` is the translated name the caller shows.

```clj
[:> task-status* {:status (:status task)
                  :label (tr "workspace.tasks.status.open")}]
```

## Usage guidelines (design)

Open and won't do are neutral. Done is blue: the task waits for someone
to verify it. Reopened is orange: it needs work again. Verified is green
and closes the task.
