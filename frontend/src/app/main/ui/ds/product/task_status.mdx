# TaskStatus

The state of a task: a word in the colour of the state.

<Canvas of={TaskStatus.AllStatuses} />

## Technical notes

`status` is one of `open`, `done`, `reopened`, `verified` and `wont-do`;
`label` is the translated name the caller shows.

```clj
[:> task-status* {:status (:status task)
                  :label (tr "workspace.tasks.status.open")}]
```

## Usage guidelines (design)

Open is blue: the task needs work. Done is green: it waits for someone to
verify it. Reopened is orange: it needs work again. Verified is purple and
closes the task. Won't do is red and drops it.
