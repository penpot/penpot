# ReviewLabel

Says that a comment or a task belongs to a design review, with the name of
the review.

<Canvas of={ReviewLabel.Default} />

## Technical notes

A long name is cut with an ellipsis, and the whole name shows as its
`title`.

```clj
[:> review-label* {:label (:review-title task)}]
```
