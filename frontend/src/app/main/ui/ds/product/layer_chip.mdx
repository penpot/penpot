# LayerChip

A chip naming a layer, or what a comment points at.

<Canvas of={LayerChip.AllChips} />

## Variants

`is-lost` marks a layer that was deleted: the chip turns orange and shows
a warning. `is-struck` also strikes its name through.

## Technical notes

`icon` replaces the board icon, except on a lost layer.

```clj
[:> layer-chip* {:label "Card form"
                 :icon i/pin
                 :is-lost (dwtk/lost? task)}]
```
