# Textarea

A text area of several lines.

<Canvas of={Textarea.Default} />

## Technical notes

It takes the props of a `textarea` (`value`, `rows`, `max-length`,
`placeholder`, `on-change`...). Name it with `aria-label` or a `label`.
Set `--textarea-resize` through `class` to change how it resizes.

```clj
[:> textarea* {:value value
               :rows 3
               :aria-label (tr "workspace.tasks.title")
               :on-change on-change}]
```
