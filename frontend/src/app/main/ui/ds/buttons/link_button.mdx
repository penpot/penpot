# LinkButton

An action that reads as a link inside a line of text.

<Canvas of={LinkButton.AllTones} />

## Variants

`tone` is `accent` (default), `info` or `neutral`.

## Technical notes

It renders a `button`, so use it for actions; a link that navigates is an
`a`. `icon` goes before the text.

```clj
[:> link-button* {:icon i/add :on-click on-add}
 (tr "workspace.tasks.new-task")]
```
