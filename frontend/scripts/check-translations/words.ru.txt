# Word catalog for check-translations.js (Russian).
# Comment lines start with #. Blank lines are ignored.
#   [function] short function words; a token starting with one of
#              these is likely missing a space (ивкладка style).
#   [common]   ordinary words used to judge the other half of a split.
#   [ok]       correct words the splitter would flag; never report
#              these. Add new valid words here when the gate trips.
#   [brands]   extra locale-specific brands/terms kept as-is.
#   [elision]  letters elided with an apostrophe (Russian has none).
#
# NOTE (Russian): Russian inflects (проект -> проекта, файл -> файла),
# so one-letter words (в, с, к, о, у, а, и) and common endings/particles
# (на, по, не, ли, же, бы, его, их, ...) are DELIBERATELY absent from
# [function]: listing them flags every inflected noun as a glued word.
# The gate still catches placeholder/plural/punctuation errors plus
# long content-word glues (review warnings).
