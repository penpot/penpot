# Catalan UI conventions

- Follow IEC and Termcat. Address the user in second-person plural in prose (`Deseu`, `Creeu`); use short imperatives in controls (`Crea`, `Mou`, `Restaura`). Shortcut names are actions, not sentences.
- Match existing Penpot vocabulary when it conflicts with a generic glossary. Keep `tauler` for board, `traç` for stroke, `drecera` for shortcut and `porta-retalls` for clipboard. Use `graella` for grid except where the existing grid-layout UI deliberately keeps `grid`. Read the neighboring entries in `ca.po` before normalizing apparent duplicates.
- Use the middle dot in ela geminada (`Cancel·la`); preserve all-caps source text when intended. An English word reused as a noun and a verb can legitimately have distinct translations (`Còpia` vs `Copia`).
