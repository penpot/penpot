# render-wasm shape and tile rendering

- `ShapesPool::get` can return a modified clone; `get_raw` bypasses derived modifiers and structure. Hierarchy is separate from shape data. `set_parent_for_current_shape` updates parent metadata, not children; keep both sides consistent without adding duplicates.
- Setters may silently skip mutation without a current shape. During bulk loading, touch operations skip tile invalidation; finish loading before text layout and final view setup. Deleting children marks descendants deleted and removes them from indexed tiles so undo/redo and panning do not show stale pixels.
- Interactive transforms and viewport fast mode have different flush behavior. Interactive modifier invalidation is deferred until render, while non-interactive updates invalidate immediately. `set_modifiers_end` cancels pending async render; its caller must request the final full-quality render. See `set_modifiers_start`, `set_modifiers_end` and `process_animation_frame`.
- Zoom overlays cache tiles by scale. Invalidate cached tiles intersecting both old and new extents on edits, not only the current-scale tiles. At zoom settle, visible tiles present before interest-ring work; defer the crop-cache rebuild to `Full`. Check pending tile pop order before changing priorities.
- Direct painting, image layers, text layout reuse and frame shadows depend on rendering guards. Consult `can_render_directly`, `draw_image_fill`, `has_usable_paint_layout` and `uses_direct_container_drop_shadow` with their tests before broadening an optimization: modifiers, styles or effects can require a different surface or fresh layout.
