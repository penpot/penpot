# Version control

This page will describe how version control for Penpot files works: branches, pull requests, reviews, and merges. The description will be written when the feature is proposed for merging into `develop`, against the code that the proposal ships.

The feature is under active development behind the `:branching` product flag. A description written now would go stale with every change, so this page holds no description until then.
